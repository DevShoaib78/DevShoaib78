I build digital products end to end — the interface, the code underneath, and the deployment that
puts them in front of people. Over twenty are live right now, across marketplaces, cybersecurity,
logistics, AI and community platforms, in **India and Saudi Arabia**.

Co-Founder at **[OneThing Studio](https://onething.studio)** · previously co-founded **Academic Ally**.
